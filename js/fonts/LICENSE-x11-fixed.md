x11-fixed-bold-7x13.ttf is a TrueType conversion of the X11 core "Fixed"
bitmap font (the 7x13 bold weight), the same bitmap font family libgd's
default font functions (gdFontSmall, gdFontMediumBold, etc.) were
originally derived from.

The embedded font metadata carries the original X Consortium notice:

    Public domain font. Share and enjoy.

TTF conversion source: https://github.com/gamache/x11-fonts-ttf
(file: "7x13B-Fixed Bold.ttf")
